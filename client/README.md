# Artisan Booking Client

React/Vite front-end for the Koforidua Artisan Booking System.

## Scripts

```bash
npm run dev
npm run build
npm run lint
```

## Main workflows

- Search and filter artisans by category, location, availability, skill, and rating.
- Submit booking requests for a selected artisan.
- Register artisan profiles with service category, pricing, skills, and availability.
- Review booking history and notification updates.
